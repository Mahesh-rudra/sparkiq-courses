How it works

Every lesson works the same way

You do not just read about Arduino. In each lesson you build the circuit and watch your code run.

🔧

1. Wire it

Connect each wire on a virtual Uno, one step at a time, with the circuit diagram beside you.

▶️

2. Run the code

See each line highlight as it runs, with a live graph, Serial Monitor or scope showing the result.

🎛️

3. Experiment

Change values in the code, turn a knob, press a button, and see what happens straight away.

🏆

4. Challenge and quiz

Finish with a short challenge and a quiz, so you know you understood before you move on.

FAQ

Questions

Not here? Email us and we will help.

Do I need an Arduino board?
No. The lessons use a virtual Arduino Uno in your browser, so you can learn everything without buying any parts. When you later buy a board, what you learned carries over.
Can I learn on my phone?
Yes. The lessons are built to work on a phone screen as well as on a laptop.
I have never done electronics or coding. Is that fine?
Yes. Level 1 starts with what a microcontroller is and builds up one idea at a time.
What is free?
In Level 1, sections 1 to 3 (14 lessons) are free: the Uno board, installing the IDE, your first Blink upload, basic electronics, and Digital output, where you wire a real LED circuit and run code on the simulator. In Levels 2 and 3, the first lesson of every section is free, so you can see displays, sensors, motors, memory and input devices working before you buy.
Do I need Level 1 before Level 2?
You need the skills, not the purchase. Level 2 assumes you can use variables, if, loops, analogRead and PWM. If you are new to Arduino, start with Level 1. If you want everything, the bundle gives all three levels for ₹699.
What is in Level 3?
Level 3 is advanced: interrupts and timers, communication buses, power saving and a final data-logger project. It assumes Level 2 skills: millis(), libraries, sensors and displays.
How do I get help if I am stuck?
Email help@vedaxglobal.com with your name, the lesson number and what you see on screen. A screenshot helps.
